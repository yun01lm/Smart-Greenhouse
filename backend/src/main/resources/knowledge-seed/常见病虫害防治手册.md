# 常见病虫害防治手册

## 一、主要病害防治

### 1. 晚疫病
症状：叶片出现水渍状暗绿色病斑，潮湿时病斑背面产生白色霉层，果实变褐腐烂。
防治：加强通风降湿，发病初期喷施烯酰吗啉或霜脲氰，7-10天一次，连喷2-3次。

### 2. 早疫病
症状：叶片出现同心轮纹状褐色病斑，茎部病斑凹陷，果实蒂部发病形成黑褐色病斑。
防治：选用抗病品种，轮作倒茬，发病初期喷施代森锰锌或苯醚甲环唑。

### 3. 灰霉病
症状：花果和叶片出现灰色霉层，病部软化腐烂，是低温高湿季节的主要病害。
防治：控制棚内湿度，及时清除病叶病果，发病初期喷施腐霉利或嘧霉胺。

### 4. 叶霉病
症状：叶片背面出现黄色不规则病斑，表面生灰褐色霉层，严重时叶片枯死。
防治：加强通风，降低湿度，喷施多菌灵或甲基硫菌灵。

### 5. 病毒病
症状：叶片黄化、花叶、皱缩，植株矮化，果实畸形，主要由蚜虫传播。
防治：培育无毒壮苗，防治蚜虫，发现病株及时拔除烧毁。

## 二、主要虫害防治

### 1. 白粉虱
危害：成虫和若虫吸食叶片汁液，分泌蜜露诱发煤污病，并传播病毒。
防治：设置黄色粘虫板诱杀，喷施吡虫啉或啶虫脒，注意轮换用药。

### 2. 蚜虫
危害：群集嫩叶和嫩梢吸食汁液，传播病毒病，造成叶片卷曲。
防治：银灰色地膜驱避，喷施吡虫啉、抗蚜威，保护地可释放瓢虫。

### 3. 红蜘蛛
危害：在叶背吸食汁液，叶片出现黄白色小点，严重时叶片枯焦脱落。
防治：保持棚内湿度，喷施阿维菌素或哒螨灵，重点喷叶背。

### 4. 棉铃虫
危害：幼虫蛀食果实，造成烂果和落果，严重影响产量和品质。
防治：性诱剂诱杀成虫，幼虫低龄期喷施高效氯氰菊酯或苏云金杆菌。

## 三、绿色防控建议

1. 农业防治：选用抗病品种，合理轮作，清洁田园，及时清除病残体。
2. 物理防治：安装防虫网，悬挂黄板蓝板，使用杀虫灯。
3. 生物防治：保护利用天敌，使用苏云金杆菌、白僵菌等生物农药。
4. 科学用药：对症下药，轮换用药，严格执行安全间隔期，优先选用生物农药和低毒农药。
