# 番茄种植技术指南

## 一、品种选择

选择适应当地气候、抗病性强、商品性好的品种。早春大棚栽培宜选择耐低温、弱光品种，如粉果型系列；越夏栽培应选择耐热、抗病毒病品种。种子应来自正规渠道，播种前进行温汤浸种处理：55℃热水浸泡15分钟，期间不断搅拌，自然冷却后继续浸泡4-6小时，沥干后催芽。

## 二、育苗技术

采用穴盘育苗或营养钵育苗。基质选用草炭、蛭石、珍珠岩按3:1:1比例配制，播种深度1厘米左右。出苗前保持基质温度25-28℃，出苗后白天20-25℃、夜间12-15℃，防止徒长。苗期保持基质见干见湿，三叶一心时分苗或间苗，定植前7天开始炼苗。

## 三、整地施肥

定植前15天深翻土壤30厘米以上，结合整地每亩施入充分腐熟的有机肥3000-4000千克、复合肥50千克、过磷酸钙50千克。采用高畦栽培，畦高20-25厘米，畦宽1.2-1.5米，覆盖地膜保温保湿防草。

## 四、定植管理

春季大棚栽培当10厘米地温稳定在12℃以上时定植，每亩定植2500-2800株。定植后立即浇定根水，3-5天后浇缓苗水。缓苗期白天保持28-30℃，促进根系生长；缓苗后适当降温，白天25-28℃、夜间15-18℃。

## 五、温光水肥管理

结果期白天温度控制在25-28℃，夜间15-18℃，地温保持20℃以上。光照不足时及时清洁棚膜、张挂反光幕。浇水遵循"见干见湿"原则，开花坐果期适当控水防止落花落果。进入采收期后，每次采收前追施高钾水溶肥，每亩5-8千克，配合叶面喷施磷酸二氢钾。

## 六、花果管理

使用番茄灵或防落素蘸花保果，浓度按产品说明配制，避免高温时段操作。每穗保留3-4个发育良好的果实，及时疏除畸形果、裂果。单秆整枝，及时打掉侧枝和下部老叶，改善通风透光。第一穗果坐住后开始留果，防止营养生长过旺。

## 七、常见问题与对策

1. 落花落果：多为温度过高过低、光照不足或营养失调所致，应加强温光管理，适当补充硼肥。
2. 裂果：与水分剧烈变化有关，应保持土壤水分均衡，避免久旱后大水漫灌。
3. 空洞果：氮肥过多、光照不足或花期温度异常导致，应平衡施肥，控制夜间温度。
4. 脐腐病：缺钙引起，应叶面补钙，保持水分供应稳定。
